Questions

The specific things people search for before they try a planning tool.

  • How do I keep a project plan in sync across Claude Code sessions?Short answer: stop keeping the plan in the conversation.
  • The agent marked every task done — why did the deadline still slip?Because <em>done</em> is a property of a task, and the delivery date is a property of a graph.
  • What is a critical path, and why does an AI project need one?The critical path is the longest chain of dependent work in the plan.
  • How do I break an AI coding project into a WBS?Break it down by what can be verified independently, not by what feels like a phase.
  • How do I track dependencies between tasks an agent executes?Record them as data, not as instructions in a prompt.
  • Is there an MCP server for a project plan?Yes — KaidoPlan has one built in.
  • Why do AI-assisted projects still miss deadlines?Because writing code faster does not shorten the chain that decides the end date — and it makes the plan look healthy while that chain stays exactly as long as it was.
  • How do I export a delivery report for a client?A delivery report is not a screenshot of a task list.

What the agent can do

The 21 MCP tools and the CLI, grouped by what you would actually ask for.

  • The plan is a file, not an accountThree tools, one object: a <code>.
  • Tasks and the WBSSix tools that cover the structure: create, read, filter, change, delete, and bulk import a breakdown you already have.
  • Scheduling and the critical pathTwo tools turn a dependency graph into an answer: when does this finish, and which tasks decide that.
  • Violation checksThe plan admits what is broken, on demand, in a list you can act on.
  • Status write-backThe difference between an agent that reports progress and one that records it: a completion time that a conflict check can use.
  • ResourcesA plan that says <em>three days</em> is making an assumption about who is doing the work.
  • Baselines and varianceWithout a frozen schedule, <em>it slipped</em> is an opinion.
  • The command lineEverything the app can do to the plan, from a terminal — which is also the shortest path to putting a schedule check in CI.
  • Connecting an agentFive clients, one switch each.
