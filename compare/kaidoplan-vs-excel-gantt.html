KaidoPlan vs a spreadsheet Gantt

The spreadsheet was never the problem. The problem is that an agent cannot safely be the one editing it.

Updated 2026-11-08 · by cygnus, the developer of KaidoPlan

What a spreadsheet genuinely does well

A sheet with a date column and conditional formatting is a real Gantt for small projects. It is free, everyone can open it, the formulas are yours, and a project manager who knows the file can predict exactly how it behaves. Nothing below argues that this is unprofessional.

Three things it does badly matter more than they used to:

  • A formula is not a scheduler. A sheet can subtract dates. Turning dependencies into earliest and latest start dates, propagating them through a chain, and computing slack is a graph algorithm that most sheets only approximate — usually by having a human look at it.
  • There is no schema. A moved column, a merged cell, or a date typed as text breaks the logic silently. The sheet does not fail; it reports a wrong date with full confidence.
  • An agent cannot safely write to it. This is the decisive one. The plan is now edited by Claude Code, Codex or a similar agent, and a spreadsheet is the worst possible target for programmatic edits: no schema, no validation, and a single misplaced row silently corrupts the schedule.

When the spreadsheet wins

If the plan is edited by people only, on mixed operating systems, and someone enjoys maintaining the formulas, the sheet is fine — and moving it would cost more than it returns. The case for KaidoPlan begins the moment an agent writes to the plan, because then "cannot be silently corrupted" stops being a preference and becomes a requirement.

Migration is not a project: export the task list, import it with wbs_import, add the dependencies, and let the schedule compute. The interesting output is not the chart. It is the list of date conflicts your sheet was already hiding.

Questions this page does not answer

Can I export back to CSV or a spreadsheet?

The plan is a plain JSON file, so any spreadsheet can be fed from it with a short script. Delivery-report export is a separate feature with a monthly limit on the free tier.

Does it print a Gantt chart?

The app draws a Gantt in the workbench. It is not a replacement for a slide deck, and it does not try to be.
