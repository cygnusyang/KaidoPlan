# KaidoPlan

A project planning workbench for people and AI. Claude Code and Codex do the work; KaidoPlan keeps the WBS, dependencies, schedule and progress in one plan both sides can inspect.

**[Download for macOS](https://github.com/cygnusyang/KaidoPlan/releases/latest)** · **[Website](https://kaidoplan.cygnusyang.top/)** · **[中文](https://kaidoplan.cygnusyang.top/zh.html)** · **[Privacy](https://kaidoplan.cygnusyang.top/privacy.html)**

macOS 14 (Sonoma) or later · universal binary (Apple silicon and Intel) · plans are local `.kaido` files

## Install

**Homebrew** — one command, keeps the app updated:

```
brew install --cask cygnusyang/kaidoplan/kaidoplan
```

**Or download** `KaidoPlan-vX.Y.Z.dmg` from the [latest release](https://github.com/cygnusyang/KaidoPlan/releases/latest) and drag it to Applications.

## CLI and MCP server

`kaidoplan` (CLI) and `kaidoplan-mcp` (MCP server) let AI agents read plans; KaidoPlan Pro unlocks write-back through the same tools:

```
brew install cygnusyang/kaidoplan/kaidoplan-cli
```

## Pricing

The app is free: the whole planning workbench — WBS, groups and milestones, dependencies, Gantt and critical path, validation and progress tracking — plus three delivery-report exports a month. **KaidoPlan Pro** adds AI write-back (task status, actual dates and new tasks through the MCP / CLI tools) and unlimited exports. Previewing a report is always free.

**$9.99 per year.** On the Mac App Store it is a subscription; direct-download builds are activated with a license file. Cancellation and refund terms are in the [refund policy](https://kaidoplan.cygnusyang.top/refund.html).
