Connecting an agent

Five clients, one switch each. The configuration file keeps its formatting, its key order and its other servers.

Updated 2026-11-08 · by cygnus, the developer of KaidoPlan

What the switch does

Turning on a client writes its MCP configuration for you: Claude Desktop, Claude Code, Cursor, Codex and WorkBuddy each have a row with a switch. Turning it off removes the same entry. The editor is text-preserving — it adds or removes only mcpServers.kaidoplan (for Codex, [mcp_servers.kaidoplan]), so indentation, key order and line endings in the rest of the file are untouched.

Each row reports its own state: connected, configuration needs updating, write failed with a reason and a retry, not connected, client not installed. A failure in one client does not affect the others.

Stdio without a separate install

The app binary can run as a stdio MCP server with --mcp-stdio. That mode is intercepted very early in launch: no window, no Dock icon, nothing to close. A client can therefore start the app itself rather than depending on a separately installed CLI.

The security defaults

  • Loopback only — never the LAN, never the internet.
  • A bearer token generated locally must accompany every request; it is shown in the panel and can be reset.
  • Only folders authorized in the panel are reachable.
  • Since v3.4.0 the service is on by default on 127.0.0.1; an existing explicit off setting is respected rather than overwritten.

Ports

The first successful bind is persisted, so restarts prefer the same port. If it is taken, the app falls back through a private range of 56 ports without changing the stored preference — so the next launch still tries your port first.

Free tier, again

Connecting a client is free and read access is free. Write-back tools are gated by the Pro licence after the trial, and the refusal happens before anything touches the disk.

Questions this page does not answer

Do I have to use the switch?

No. A copy-configuration button remains as the manual path for anyone who wants to place the entry themselves.

What happens when the token changes?

Configurations of enabled clients are rewritten automatically, so you do not have to re-paste them.
