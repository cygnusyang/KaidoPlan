Tasks and the WBS

Six tools that cover the structure: create, read, filter, change, delete, and bulk import a breakdown you already have.

Updated 2026-11-08 · by cygnus, the developer of KaidoPlan

The tools

ToolDoes
task_addCreates a task with effort, assignee, dependencies and constraints. A constraint is written as type:ISO8601, e.g. startNoLaterThan:2026-11-05T00:00:00Z.
task_listLists tasks, optionally filtered by parent or by a natural-language filter.
task_getReturns one task in full — the cheap way to check state before changing it.
task_updateChanges fields. Passing an empty string to assignee clears the owner rather than writing a blank one.
task_deleteDeletes a task and its subtasks, and drops dependencies that pointed at them, so no dangling edges are left behind.
wbs_importBulk-imports a nested task tree instead of retyping a breakdown that already exists.

Structure, not fields

Groups carry hierarchy; milestones are the points where someone else has to agree; tasks carry the work, an estimate and the edges. An agent that only adds flat tasks produces a list that cannot be scheduled — which is the most common way a "generated plan" fails.

Importing what you already have

wbs_import takes a nested tree and turns it into the plan. The estimate and the dependency step that follow are the ones that need a human: an imported outline with no edges schedules to a single day, and the resulting date is meaningless rather than wrong.

kaidoplan wbs import --file plan.kaido
kaidoplan task list --file plan.kaido

Deletion is honest

A deleted task takes its dependencies with it. The alternative — leaving edges pointing at a task that no longer exists — produces a schedule that either fails or silently ignores the edge, and both outcomes are worse than a clean delete.

Questions this page does not answer

Do milestones behave like zero-duration tasks?

They are the points that other tasks depend on, which is why they matter for the schedule. Treat them as checkpoints, not as work.

Can an agent rewrite the whole plan at once?

It can call the write tools in sequence. There is no bulk overwrite operation, and that is intentional: a plan replaced wholesale is a plan nobody reviewed.
