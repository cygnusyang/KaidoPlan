KaidoPlan 隐私政策

最后更新：2026-11-15

KaidoPlan（下称「本应用」）不收集你的个人数据，不在后台向任何地方发送信息。唯一的对外传输 是你主动提交的反馈：只有你在「帮助 ▸ 反馈问题…」里写下内容并点击提交时，你选定的内容才会被 发送，并在公开仓库的 issue 中公开可见。

  • 不收集数据：本应用不含账号系统、行为分析、后台崩溃上报、广告或第三方 SDK， 也不会在后台自动上传任何内容。
  • 你主动提交的反馈（唯一的对外传输）：只有你在「帮助 ▸ 反馈问题…」面板里 点击提交才会发送，不点提交则内容留在本机。发送内容为你填写的描述、机器信息（版本号、构建号、 分发渠道、macOS 版本、机型标识、界面语言、许可证类型），以及仅在你显式勾选时 才打包的日志与崩溃报告（日志在打包前会脱敏，路径只保留末两级）。反馈会发布到本项目的 公开 issue 列表，任何人可见、 可搜索，并可能被搜索引擎及第三方归档；以你自己的 GitHub 账号提交时 issue 显示该账号名， 由维护者账号（GitHub cygnusyang）代为提交时，不显示你的账号信息（正文与你自己 提交完全相同）。提交后你无法自行删除——如需删除，请在原 issue 下留言。 不会上传：.kaido 项目文件的内容、项目文件路径、最近项目书签、 许可证文件内容、你的邮箱。
  • 项目数据留在本地：你打开和保存的 .kaido 文件只存在你选择的位置。 本应用不上传、不备份、不同步任何项目内容。
  • 最近项目：为了在启动时重新打开上次的项目，本应用在你明确选择文件或文件夹后， 会为该文件生成一个仅限本应用使用的 security-scoped bookmark，保存在本机偏好设置里。 删除「最近项目」或移除授权目录即可清除。
  • MCP 服务（默认关闭）：你在「项目 ▸ MCP 服务…」中手动开启后，本应用会在 127.0.0.1 上监听本地端口，供本机运行的 AI 客户端读写同一份计划。
    • 只监听回环地址，不接受来自局域网或互联网的连接；
    • 每个请求必须携带本应用在本机生成、并显示在该面板中的访问令牌；
    • 只有你在该面板中授权的文件夹可被访问，越界请求会被拒绝；
    • 随时关闭开关或重置令牌即可立即中断访问。
  • 无第三方共享：除你主动提交的反馈由 GitHub 以公开 issue 形式承载外， 本应用不与任何第三方共享数据，因为不存在其它可共享的数据。

如对本政策有疑问，请通过项目主页 github.com/cygnusyang/KaidoPlan 的 Issues 联系。
